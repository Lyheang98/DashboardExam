# 🚀 Quick Start Guide - Dashboard App

## For Managers & Stakeholders

---

## ⚡ Get Started in 3 Steps

### Step 1: Start the Application
```bash
cd dashboard-app
npm install    # First time only
npm run dev
```

### Step 2: Open in Browser
```
http://localhost:3000
```

### Step 3: Login with Test Account
| Field | Value |
|-------|-------|
| **Email** | john@example.com |
| **Password** | password123 |

✅ You're now in the dashboard!

---

## 🎯 What Can You Do?

### Users Page
- 📊 View all users in a table
- 🔍 Search by name or email
- 🏷️ Filter by role or status
- ➕ Add new users
- ✏️ Edit user details
- 🗑️ Delete users
- ⭐ Toggle active/inactive status

### Products Page
- 📊 View all products
- 🔍 Search products
- 💰 Filter by price range
- 🏷️ Filter by category
- ➕ Add new products
- ✏️ Edit product details
- 🗑️ Delete products
- ⭐ Toggle availability status

## ❓ Troubleshooting

**Problem**: Can't login
- **Solution**: Check TEST_LOGIN.md for credentials

**Problem**: Page not loading
- **Solution**: Refresh page or clear browser cache

**Problem**: Data not showing
- **Solution**: Open browser console (F12) to see errors
